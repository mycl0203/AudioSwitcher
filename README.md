# AudioSwitcher 3

现代化的音频设备快速切换工具，支持自定义设备组、快捷键绑定、系统托盘集成和美观的用户界面。

## 功能特性

- 🎵 **设备组管理**：配置多个输入/输出设备组合，一键切换
- ⌨️ **快捷键绑定**：为每个设备组设置全局快捷键
- 🔇 **麦克风静音**：快速切换麦克风静音状态
- 📥 **系统托盘**：最小化到托盘，右键菜单快捷操作
- 🎨 **现代化UI**：采用 CustomTkinter 构建的美观界面
- ✨ **智能提示**：操作反馈和错误提示
- 💾 **自动保存**：配置自动持久化

## 安装要求

- Python 3.8+
- Windows 10 或更高版本

## 安装步骤

1. 克隆或下载项目
```bash
git clone <repository-url>
cd AudioSwitcher3
```

2. 安装依赖
```bash
pip install -r requirements.txt
```

3. 运行程序
```bash
python main.py
```

## 依赖库

- customtkinter - 现代化UI框架
- pystray - 系统托盘支持
- Pillow - 图像处理
- keyboard - 全局快捷键支持
- pycaw - Windows 音频控制

## 使用说明

1. 启动程序后，主界面会显示当前活动的设备
2. 在「设备管理」标签页添加或编辑设备组
3. 为每个设备组设置可选的快捷键
4. 使用「快速切换」标签页切换设备
5. 点击窗口关闭按钮会最小化到系统托盘

## 功能细节

### 设备组配置
- **显示名称**：自定义设备组名称（自动根据设备名生成）
- **输出设备**：选择扬声器/耳机等输出设备
- **输入设备**：选择麦克风等输入设备
- **快捷键**：可选，全局快捷键绑定（例如：Ctrl+Alt+1）

### 托盘菜单
- 显示当前活动设备组
- 快速切换所有已配置的设备组
- 快捷键提示在菜单中显示（如果已配置）
- 麦克风静音/取消静音
- 打开控制面板
- 退出程序

### 设置选项
- 开启/关闭设备切换通知
- 退出应用（在托盘菜单中也可以退出）
